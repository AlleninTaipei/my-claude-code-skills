# 程序化配樂與音效

全部用 NumPy 合成, 工具在 `scripts/videokit.py` 的 `Mixer`. 範例: `examples/taichi/audio.py` (電子), `examples/got/audio.py` (史詩), `examples/jb/audio.py` (驚悚, 諜報).

## 先定節奏

- 先決定 BPM, 讓畫面段落剛好是整數小節. 120 BPM 一小節 2 秒; 96 BPM 一小節 2.5 秒.
- 把所有重點時間 (剪接點, 劍擊, 螢幕點亮, 標題) 定義成常數, 畫面和音訊共用同一份. 例如 `CLASHES = (16.25, 17.5, ...)` 放在 audio.py, render.py 再 import.
- 重擊前留 0.1 到 0.6 秒的近乎靜音, 「先安靜再爆發」的張力最強.

## 風格配方

| 風格 | 元素 |
|---|---|
| 科技產品 | 4/4 kick, 反拍 hi-hat, 拍手在 2/4 拍, 反拍貝斯, 隨 kick 做 sidechain 的襯底和弦, 段落間 riser 加 whoosh, 16 分音符琶音 |
| 史詩, 奇幻 | 低音持續音, 大提琴固定音型 (8 分音符, 帶顫音), 太鼓, braam (低音銅管叢集, 濾波逐漸打開), 合唱 'ah' (鋸齒波經過 800/1150/2900 Hz 共振峰), 風聲 |
| 驚悚, 諜報 | 16 分音符弦樂斷奏 (鋸齒波, 每小節換和弦), 8 分音符貝斯, 腳踏鈸, 監控嗶聲, 打字聲, riser 後先靜 0.03 秒再 boom, 快剪時每個剪接點一記小 braam, 結尾前 0.35 秒靜音 |
| 精品, 極簡 | 少量音符, 鐘聲 (正弦波加泛音), 長殘響, 一兩個重點 boom |

## 音色做法

- kick / boom / 太鼓: `sweep_sine` 音高指數下滑, 加短促噪音.
- braam: 多個低音鋸齒波, 濾波器從 250 Hz 打開到 1200 Hz, 加 boom.
- riser: 頻帶隨時間升高的噪音, 音量平方上升, 在重擊前 20ms 切斷.
- whoosh: 頻帶先升後降的噪音, 包絡呈高斯形.
- 劍擊, 金屬聲: 不協和泛音 (例如 1460, 2370, 3520 Hz) 快速衰減, 加極短的高頻噪音.
- 龍吼, 怪聲: 帶顫音的方波經帶通濾波, 再混入噪音.
- 時鐘 tick-tock: 兩種頻帶的極短噪音交替.

## 原創性

- 不要仿寫知名配樂的旋律 (例如影集主題曲). 只借風格: 調性, 樂器, 節奏型態.
- 固定音型自己編, 用和弦音上下跳動即可.

## 效能

- 30 秒 48kHz 是 144 萬個樣本. 固定截止頻率的濾波用 `fft_filter`, 不要寫逐樣本的 Python 迴圈.
- 隨時間變化的濾波: 預先做幾個頻帶的噪音, 再依時間加權混合 (見 got/audio.py 的 `swept_noise`).
- `env` 對負時間會算到 exp 溢位, videokit 版本已經用 errstate 處理.

## 混音與檢查

- `Mixer.master()`: 殘響, 22 Hz 高通, tanh 飽和, 結尾淡出, 峰值正規化到約 -1 dBFS.
- 用 `loudness_report` 或 `scripts/verify_video.py` 看每段音量. 健康的預告片曲線大致是: 開場 -25 dB 左右, 主段落 -12 到 -14 dB, 標題重擊最響, 結尾回落.
- 模型聽不到聲音. 交付時要說明「只量過音量, 沒有實際聽過」, 請使用者自己聽.
